# Justin Olivo | Clinical AI Engineer Portfolio

Personal portfolio site for Justin Olivo, a clinical AI engineer building agentic AI systems for healthcare. It is aimed at healthtech employers, hospital systems, and clinical teams.

## What's on the site

- Background: nine years in a Level II trauma center ER, U.S. Army veteran
- Case study: CardioBot, a multi-model RAG clinical decision support assistant ([live demo](https://cardiodoc.streamlit.app), [code](https://github.com/JustinOlivo52/cardiobot))
- Projects in progress, services, experience, and contact options

CardioBot is a portfolio project built for demonstration. It is not for clinical use.

## About this repo

A single static page: plain HTML and CSS with a few lines of JavaScript for the copy-email button. No build step and no dependencies. Fonts load from Google Fonts.

```
index.html   the whole site
README.md    this file
```

A sibling site aimed at general Applied AI roles lives in its own repo.

## Hosting

Deployed with GitHub Pages from the `main` branch, root folder.

## Updating
